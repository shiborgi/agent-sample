# Boas práticas de Python

- `except:` ou `except Exception:` que engole o erro sem registrar nem relançar: `major`.
- Argumento padrão mutável (`def f(x=[])`): `major`, o valor é compartilhado entre chamadas.
- Arquivo, conexão ou lock aberto sem `with`: `minor` (`major` se vazar em laço).
- Comparação com `None` usando `==`, ou `is` com literais: `minor`.
- Chamada bloqueante (`time.sleep`, `requests`, I/O de arquivo grande) dentro de `async def`:
  `major` em código de servidor.
- Laço que concatena string ou faz consulta por item (N+1): `performance`.
- Nome que diz uma coisa e faz outra (ex.: `get_` que altera estado): `maintainability`.
