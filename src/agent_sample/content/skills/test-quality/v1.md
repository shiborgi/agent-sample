# Qualidade de testes

- O nome do teste promete um comportamento; as asserções verificam esse comportamento? Se não,
  aponte como `tests`, `major` quando o teste passaria mesmo com o código quebrado.
- Teste sem asserção, ou que só verifica que "não lançou exceção", é `minor`.
- Mock que substitui justamente a unidade testada não testa nada: `major`.
- Caso de borda da mudança (vazio, limite, erro, concorrência) sem teste: `minor`, citando o caso.
- Teste que depende de rede, relógio ou ordem de execução é frágil: `minor`.
- Não peça teste para mudança só de documentação ou formatação.
